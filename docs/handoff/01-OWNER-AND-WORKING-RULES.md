2. Toujours donner l'adresse URL quand on fait référence à une page.
3. Réponses en français ; code, commits et documentation de dépôt en anglais.
4. Une manipulation à la fois quand c'est possible ; il vaut mieux lui faire coller un bloc, attendre le résultat, puis donner le suivant.
5. Dire tout de suite les contradictions et les mauvaises idées ; ne pas valider par politesse.
6. Marquer le niveau de confiance de chaque affirmation technique (vérifié avec source, probable, à vérifier) et dire quand l'accès au web manque.

## Contraintes absolues
- Sécurité : on pilote du matériel qui peut blesser ou casser. Un agent ne se connecte jamais à une machine réelle de sa propre initiative ; tout essai sur matériel est une procédure écrite que le propriétaire lance lui-même. Un arrêt logiciel ne remplace jamais un arrêt d'urgence matériel.
- Gratuit : ne proposer aucun outil payant sans le signaler et sans son accord.
- Licences : vérifier avant de recommander une licence ou de réutiliser du code. Aucun code copié de projets GPL.
- Simplicité : solutions éprouvées, dépendances légères et justifiées.
